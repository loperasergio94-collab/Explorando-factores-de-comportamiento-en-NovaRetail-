# Explorando-factores-de-comportamiento-en-NovaRetail-
Análisis de 15.000 registros de NovaRetail+ para identificar patrones de comportamiento de clientes e ingresos. Utilicé Python, Pandas, NumPy y herramientas de visualización para explorar datos, evaluar correlaciones estadísticas y generar hallazgos relevantes para la toma de decisiones empresariales.
